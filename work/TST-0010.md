Bounded exploration, not a proof. The real `agent.evaluate` is run against a scripted stand-in for the model on every case within this bound:

- a Scorecard of two Criteria and a Call of two Utterances
- a turn limit of 0 to 4, and every sequence of that many turns
- thirteen kinds of turn: the model declines, its reply is cut off, it stops without a tool call, or it makes one to four tool calls that record a Finding, propose one that is rejected, finish, or name a tool that does not exist

That is 30,941 runs. Each is checked against properties L1 to L6 in `apps/call-qa-agent/tests/bounded/explore.py`: REQ-0007 for the turn limit, REQ-0001 for the Findings of a returned Evaluation. The scripted replies are plain objects, so the SDK's parsing of a response and the fallback request path are outside the bound, as is any script of five or more turns.
