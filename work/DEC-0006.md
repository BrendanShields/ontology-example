id: DEC-0006
title: The model proposes Findings and the domain layer decides the rest
status: done
bounded_context: call-qa
rationale: >-
  A language model reads a transcript well and is unreliable at arithmetic and at keeping
  to a closed list. So the model only proposes Findings, through a tool that rejects whatever
  the ontology does not allow and says what it would have accepted. The score, the outcome
  and the disposition are computed from the accepted Findings by code and are never taken
  from the model.
uses_terms: [Finding, Rejection, score, evaluation_outcome, disposition]
decided_by: call-qa squad
decided_on: '2026-09-22'
