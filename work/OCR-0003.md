id: OCR-0003
proposed_term: RejectionRule
proposed_definition: >-
  No definition changes. RejectionRule gains the annotation binding: rule; score, evaluation_outcome
  and disposition gain binding: computed; findings gains minimum_cardinality 1.
justification: >-
  A gate (onto rules) can then fail when a declared rule has no function that produces it
  or no verified Requirement. Validation found 4 of 6 RejectionRule values with no proof chain,
  and that the generated types accept an Evaluation with no Findings while the generated SHACL
  rejects it.
title: Declare which call-qa terms are rules and computed values
status: draft
bounded_context: call-qa
