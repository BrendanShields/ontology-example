---
id: REQ-0011
ears_text: >-
  If a `Scorecard` holds two `Criterion` entries with the same `criterion_id`, then the call-qa-agent
  shall not load the `Scorecard`.
uses_terms: [Scorecard, Criterion, criterion_id]
risk_tier: medium
title: A Scorecard with a repeated criterion_id is not loaded
status: done
bounded_context: call-qa
---

The glossary calls `criterion_id` the identifier of a Criterion, and REQ-0001 counts Findings by it. A Scorecard with two Criteria named alike used to load and take one Finding for both. `call-qa` now refuses the file with a `ValueError` before any request is made. A Scorecard built in code is not checked here: REQ-0010 stops an Evaluation being concluded from it.
