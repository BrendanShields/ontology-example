This robot is the agent. I drew it restless on purpose, because an agent is probabilistic. It samples each time it runs, and it can give a different answer to the same request. I've used coding agents every day for the last year, and I expect most of you have too. They are fast on boilerplate. They also cause subtle regressions when they don't know the domain.
